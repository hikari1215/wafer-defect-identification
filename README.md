# wafer-defect-identification
Using YOLO26 to identify wafer defect (in development)

Dataset for SEM: [Link](https://drive.google.com/drive/folders/1Xsb9yUR8h2aenMd1tMkmzNmNtlRWWjPP?usp=drive_link)

### Training & Validation Visualizations

| File Name | Category | Description |
| :--- | :--- | :--- |
| **`train_batch*.jpg`** | Augmentation Samples | Visualizations of training batches with applied augmentations (Mosaic, rotation, and Random Erasing masks). |
| **`val_batch*_labels.jpg`** | Ground Truth | Actual defect class labels for validation batches. |
| **`val_batch*_pred.jpg`** | Model Predictions | Class predictions generated by YOLO26s-cls on validation batches for visual accuracy verification. |
